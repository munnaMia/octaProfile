# API endpoint

## Users accounts

- `POST /users` -> Create an new user account
- `DELETE /users/{id}` -> Delete an user account
- `PATCH /users/{id}` -> Update some informaiton of an user account
- `GET /users/{id}` -> Get an user account information

## Posts manage

- `POST /posts` - Create new a post
- `GET /posts/{id}` - Get a specific post for any log user
- `DELETE /posts/{id}` - Delete a post for authorized users only
- `PATCH /posts/{id}` - Update a post information for authorized users only
